# Project Gutenberg ebook 76404 source snapshot

This snapshot contains the complete historical text of Isaac Newton’s *Newton’s Principia: The Mathematical Principles of Natural Philosophy* (Andrew Motte translation, 1846 Chittenden edition), including *The System of the World*.

- Project Gutenberg: https://www.gutenberg.org/ebooks/76404
- Public GitHub mirror used for retrieval: https://github.com/sigma5a/Principia-Modern
- Mirror commit: `15a0a48530804c6ce49100656a2046aeb77d3b89`
- Retrieved: 2026-11-09

`76404-h.htm` retains the Project Gutenberg header, credits, license, all inline `data-tex` formula source, and references to the 274 original JPG images copied under `images/`. `system-of-world.html` is the mirror's source-faithful split of the complete *System of the World* section and is used for the standalone prefab. The mirror’s modern commentary and interactive experiments are not part of this source snapshot.
